# vote-pulse-app
Описание:
Это интерактивное сайт-голосование, позволяющий пользователям выбрать один из четырёх вариантов: React, Vue, Angular, Svelte. После голосования отображается текущая статистика по голосам за каждый вариант. Пользователь может голосовать только один раз, а данные хранятся на стороне клиента с помощью localStorage, что обеспечивает сохранение результатов при обновлении страницы.
Выбор одного из четырёх вариантов (React, Vue, Angular, Svelte)
Ограничение голосования одним голосом (через localStorage)
Отображение статистики голосов в виде чисел и бара с процентами
Обновляемая статистика после голосования
Реактивное обновление интерфейса после голосования
